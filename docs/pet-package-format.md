# Пакет питомца

`.pet` — обычный ZIP-архив. Также принимается расширение `.zip`. В корне лежит `manifest.json`, рядом — PNG с прозрачностью. Исходные готовые кадры сохраняются целиком, включая полупрозрачную тень. Исполняемые файлы не нужны и не запускаются.

Минимальный пример с двумя кадрами `neutral.png` и `move.png`:

```json
{
  "version": "pet-1",
  "name": "Имя питомца",
  "frameSize": [384, 500],
  "alphaPrepared": true,
  "neutral": "neutral",
  "frames": ["neutral", "move"],
  "clips": {
    "rest": [
      {"frame": "neutral", "seconds": 0.12},
      {"frame": "move", "seconds": 0.12},
      {"frame": "neutral", "seconds": 0.12}
    ]
  },
  "roles": {"lookaround": "rest"}
}
```

Все PNG должны иметь указанные размеры. Имена в `frames`, `neutral` и шагах пишутся без `.png`. Можно использовать подпапки, например `frames/idle-001`, но нельзя абсолютные пути и `..`. `alphaPrepared: true` сохраняет альфа-канал без дополнительного удаления фона. Не добавляйте зелёный фон в готовый пакет.

По умолчанию импортированные кадры не растягиваются для имитации дыхания. Движение покоя лучше подготовить в самой анимации. Необязательное `breathAmplitude` (0–0,01) включает очень малое вертикальное изменение масштаба в покое, только если это подходит персонажу. Для жёсткого робота оставьте 0. Дыхание встроенного HUDI сохранено на прежнем уровне 0,002.

Поддерживаемые роли: `think`, `dance`, `lookaround`, `wink`, `crouch`, `stretch`, `angry`, `sad`, `surprise`, `hood`, `pockets`, `combat`, `salute`, `march`, `notebook`, `fire`, `firecalm`, `dash`, `jump`, `paintmagic`, `shadowmerge`, `sidestep`, `cutthroat`, `lookdown`, `lookleft`, `lookright`, `lookup`, `temple`, `skeptical`, `shrug`, `indignation`, `firetrick`, `impatient`, `stroll`, `adjustglasses`, `groove`, `ironic`. В `roles` сопоставьте нужную роль имени клипа. Можно сразу назвать клип по роли. Набор необязателен: без `think` питомец продолжает спокойное поведение во время ответа; без `dance` праздничный жест не запускается. Клип `idle` автоматически используется как спокойное самостоятельное движение, если `lookaround` не назначен. Выбирайте действия, подходящие анатомии персонажа.

Если для прыжков или эффектов нужны дополнительные прозрачные поля, задайте `displayBounds: [x, y, width, height]` внутри `frameSize`. Эта область задаёт привычный размер и положение тела; весь холст по-прежнему отрисовывается без обрезки. При переключении питомцев сохраняются физическая высота и нижний центр этой области. Без `displayBounds` используется весь холст. Не подрезайте отдельные кадры под разные позы.

Для долгого ожидания или удержания позы добавьте необязательные диапазоны в индексах шагов клипа:

```json
"holds": {
  "think": {"start": 10, "end": 18, "seconds": 3.2},
  "pockets": {"start": 20, "end": 28, "seconds": 3.2}
}
```

Плейер проходит участок вперёд и назад с замедлением на концах. Индексы должны существовать в соответствующем клипе после сопоставления ролей. Не переносите индексы удержания HUDI в короткие клипы нового персонажа.

Ограничения импорта в HUDI 7.3.10: архив до 1 ГБ, суммарный размер записей до 1 ГБ, до 10 000 кадров, максимум 2048 по стороне и 1 мегапиксель на кадр; каждый PNG до 8 МБ. Шаг длится от 0,01 до 60 секунд. Все кадры декодируются при проверке импорта. Точные дубликаты пакета повторно не копируются. Лимит архива увеличен с 512 МБ для коллекций из двенадцати движений без дополнительного уменьшения кадров.

После импорта выберите питомца в настройках. Файл выбора и коллекция хранятся отдельно от программы, поэтому обновление установщика их сохраняет. Встроенный HUDI всегда доступен для возврата.

Для сборки пакетов есть команды `HUDI.exe --verify-pet-package <пакет> <папка QA>` и `HUDI.exe --import-pet <пакет> <путь отчёта JSON>`. Первая декодирует кадры и проигрывает действия настоящим рендерером в отдельной проверке. Вторая использует тот же импорт, что настройки, добавляя питомца в коллекцию текущего пользователя без смены выбранного персонажа. Обе возвращают ненулевой код при ошибке; подробности сохраняются в отчёте.
