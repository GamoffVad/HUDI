# Перенос персонажа в Codex

Отдельный Windows-питомец, локальный питомец Codex и облачный ChatGPT Pet — разные места установки. Сначала проверь доступные инструменты и текущую версию приложения. Не выбирай облачного одноимённого питомца вместо текущего персонажа только по названию: проверь внешность.

Для облачной коллекции используй её специализированный плагин и проверки. Для локального Codex используй поддерживаемый текущим приложением формат и его настройки. Не переносить формат и ключи из прошлого проекта без проверки: они могут меняться.

Проверенный пример локального формата: `$CODEX_HOME/pets/<unique-id>/pet.json` с `displayName`, `description`, `spriteVersionNumber`, `spritesheetPath` (относительный путь внутри папки). Локальная идентичность имеет вид `custom:<unique-id>`; выбор хранится в `desktop.selected-avatar-id`. Записывай через доступный API конфигурации с сохранением других параметров и читай результат обратно. Не перезапускай пользовательский Codex с активными задачами ради перечитывания; используй обновление/выбор в интерфейсе или сообщи, что потребуется повторное открытие настроек.

В проверенной версии v1 — прозрачный атлас 1536×1872, 8×9 ячеек по 192×208. Количество кадров по строкам: 6,8,8,4,5,8,6,6,6; оставшиеся ячейки прозрачны. v2 добавляет 16 направлений взгляда (1536×2288). Отсутствующий взгляд нельзя заменять поверх исходных глаз искусственными зрачками. Если пользователь отказался от курсорных реакций, не добавляй их без нового запроса.

При переносе готовых анимаций выбирай короткие цельные фрагменты под события хоста, сохраняй общий масштаб, опору, силуэт и тень, если она нужна по заданию. Если бег/прыжок не существует, честно обозначь адаптацию подходящим жестом; не называй её полноценной новой анимацией. Если именно эти движения требуются, сгенерируй их выбранным пользователем сервисом.

Проверь атлас структурным валидатором, прозрачность и проигрывание в масштабе хоста. Сохрани manifest происхождения кадров и предыдущее выбранное значение. Установи и сделай основным только если это входит в запрос. Прочитай обратно ID и проверь видимый выбор, если интерфейс доступен. Нельзя выдавать запись настройки за проверенное отображение живого питомца.
