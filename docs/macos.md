# HUDI для macOS

В проекте две оболочки с общим форматом пакетов `.pet`. Windows собирается из
`src/HudiPet/HudiPet.csproj` на WPF, macOS из `src/HudiMac/HudiMac.csproj`
на Avalonia. Обе используют одну библиотеку движений, очередь действий,
коллекцию питомцев и клиент API моделей.

## Сборка

Нужны Python 3, .NET SDK 10 и архив кадров HUDI. По умолчанию используется
`output/hudi-blender-v1/sprites.zip`. Другой архив можно передать через
`--sprites /путь/к/sprites.zip`.

```sh
python3 tools/fetch-hudi-sprites.py
python3 tools/package-macos.py --arch both
```

Архивы в `output/hudi-macos` содержат `HUDI.app` и собственный .NET Runtime.
Выберите `arm64` для Apple Silicon или `x64` для Intel. Минимальная версия
системы для этой сборки — macOS 14. Сборка на Mac ставит локальную подпись для
проверки. Для публичного распространения нужны подпись Developer ID,
нотаризация и запуск на Mac.

Для подписанного архива запустите на Mac с сертификатом Developer ID Application
и настроенным профилем `notarytool` в Связке ключей:

```sh
python3 tools/package-macos.py --arch x64 \
  --signing-identity 'Developer ID Application: Name (TEAMID)' \
  --notary-profile 'HUDI'
```

Скрипт создаёт архив с суффиксом `-signed.zip` после принятия Apple, проверки
нотаризационного билета и проверки Gatekeeper. Параметр `--arch arm64`
создаёт сборку для Apple Silicon.

## Управление

Правый клик по питомцу открывает меню. Перетаскивание меняет положение,
прокрутка — размер. По умолчанию двойной клик открывает избранное, двойной с ⌘ —
заметки, тройной — чат. Назначения и режим «Только при действиях пользователя»
доступны в настройках. Режим отключает самостоятельные анимации и ожидание
после паузы, сохраняя пользовательские реакции. В коллекции можно импортировать
или экспортировать `.pet` вместе с его оформлением.

В HUDI 7.3.25 настройки открываются рядом с питомцем. Пока открыта панель,
питомец уступает ей место поверх окон. Перетащить панель можно за заголовок.
Каждая заметка открывается в отдельном окне; размер меняется за нижний правый
угол и сохраняется. Панель инструментов появляется при активации заметки.
На Mac редактор заметок пока поддерживает обычный текст. Заметку с
форматированием или изображениями можно прочитать или скопировать в текстовую
заметку, сохранив оригинал для Windows.

Данные macOS находятся в `~/Library/Application Support/HUDI`. Программы в
избранном указываются путями к `.app`. Ключ API хранится в Связке ключей macOS,
поэтому при переносе настроек с Windows ключ потребуется ввести заново.
Переключение приложений, набор и паузы определяются по активному приложению
и счётчикам Core Graphics. Реакции на буфер обмена пока доступны в Windows.

## Проверка

Если Finder не показывает питомца после запуска, распакуйте ZIP в macOS,
перенесите `HUDI.app` в «Программы» и запишите точный текст предупреждения.
Проверить архитектуру и увидеть ошибки загрузчика можно в Терминале:

```sh
uname -m
sw_vers -productVersion
/Applications/HUDI.app/Contents/MacOS/HUDI
```

В HUDI 7.3.22 исключение во время старта приложения дополнительно сохраняется в
`~/Library/Application Support/HUDI/startup-error.txt`. Если сбой происходит
до запуска HUDI, например в Gatekeeper или системном загрузчике, этого файла
не будет. Используйте сообщение Finder или вывод Терминала.

```sh
./HUDI.app/Contents/MacOS/HUDI --verify-runtime /tmp/hudi-verification
```

Команда использует отдельный каталог данных. Для 7.3.25 она проверяет запуск,
прозрачность, воспроизведение, режим анимаций и расположение панелей.
На Windows оболочка Avalonia прошла эту проверку. Для обоих архивов проверены
версия, архитектура и права на запуск. На Mac отдельно проверьте, что питомец
следует за указателем до нижней границы экрана, а настройки можно перемещать
и нажимать при включённом режиме «Поверх окон».
