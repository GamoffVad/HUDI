# Реакции на действия пользователя

С версии 7.3.23 реакции включены по умолчанию для всех питомцев. Переключатель «Реагировать на мои действия» находится в разделе «Управление» рядом с назначениями кликов. Выбор сохраняется отдельно для каждого питомца.

HUDI выбирает из движений текущего питомца. Сначала он ищет подходящую сцену, которая ещё не играла в этом круге, затем выбирает любое из оставшихся движений. При неизменных условиях все доступные движения проигрываются до повтора. Сцены у края доступны там, где они полностью помещаются на экране.

| Событие | Пример реакции |
| --- | --- |
| Переключение в окно Word, Excel, PowerPoint, блокнота или поддерживаемого PDF-редактора | Удивляется |
| Движение мышью или трекпадом | Осматривается |
| Первое нажатие или начало серии нажатий клавиш | Задумывается или осматривается |
| Копирование файлов в буфер, включая Проводник (Windows) | Стучит по голове |
| Копирование текста в буфер (Windows) | Хихикает |
| Открытие приложения на переднем плане или переключение между приложениями | Оборачивается |
| Пауза без ввода не менее 90 секунд | Нетерпеливо ждёт |
| Возвращение после паузы | Хихикает |

HUDI видит, какое приложение вышло на передний план, и распознаёт известные редакторы. Содержимое клавиш, введённый текст, заголовки окон, имена файлов и содержимое буфера не считываются, не сохраняются и не передаются модели. Буфер проверяется только на наличие формата текста или файлов.

Непрерывная печать или движение мыши считаются одним действием до паузы примерно в 0,7 секунды. Пока идёт анимация, очередь хранит по одному ожидающему событию каждого типа. Открытие окна, печать и движение мышью не вытесняют друг друга и проигрываются по порядку без дополнительной задержки. Перетаскивание питомца, открытые окна HUDI, меню, избранное, запрос модели и пауза блокируют фоновые реакции. Отключение реакции или смена питомца очищают очередь. В режиме «Только при действиях пользователя» фоновые анимации без ввода отключены, а реакции на действия остаются активными.

Проверка: `HUDI.exe --verify-desktop-reactions <папка>`. Отчёт `desktop-reactions-tests.json` включает проверку очереди, группировки ввода, настроек, ротации движений каждого установленного питомца и подключения системных обработчиков.

В HUDI 7.3.20 «Девочка в розовом» может подойти к правому краю текущего монитора, опереться на него или выглянуть из-за него и отступить. Подвиньте её к краю и отпустите. Если реакции включены, движение запускается после завершения текущей анимации. Рядом с краем эти сцены также доступны в меню «Движения». HUDI использует замеренный в каждом кадре размах силуэта, чтобы при шаге нога оставалась внутри рабочей области, а в позе опоры ладонь совпадала с краем.

С версии 7.3.22 при отпускании у правого края HUDI при необходимости сдвигает питомца по вертикали в пределах 32 логических пикселей. Это оставляет место для всей траектории, в том числе у панели задач. Повторное перетаскивание не блокируется таймером предыдущей анимации.
