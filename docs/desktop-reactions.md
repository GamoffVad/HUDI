# Реакции на действия пользователя

Включены по умолчанию только у «Девочки в розовом». Переключатель «Реагировать на мои действия» находится в разделе «Управление» рядом с назначениями кликов. Выбор сохраняется отдельно для установленного питомца; остальные питомцы не наблюдают за действиями пользователя.

Используются существующие анимации:

| Событие | Реакция |
| --- | --- |
| Переключение в окно Word, Excel, PowerPoint, блокнота или поддерживаемого PDF-редактора | Удивляется |
| Начало серии нажатий клавиш | Осматривается |
| Копирование файлов в буфер, включая Проводник | Стучит по голове |
| Копирование текста в буфер | Хихикает |
| Переключение между приложениями | Оборачивается |
| Пауза без ввода не менее 90 секунд | Нетерпеливо ждёт |
| Возвращение после паузы | Хихикает |

Определяется активация окна редактора, а не достоверное открытие или сохранение документа. Браузерные документы не распознаются по содержимому вкладок. Набор определяется по количеству уведомлений о нажатиях: содержимое клавиш, введённый текст, заголовки окон, имена файлов и содержимое буфера не считываются, не сохраняются и не передаются модели. Буфер проверяется только на наличие формата текста или файлов; изменение формата может исходить и от другого приложения.

Между реакциями проходит не менее 12 секунд, повтор одного события — не ранее 45 секунд. При активной анимации или во время задержки ожидает только последнее событие не дольше 18 секунд. Например, начало набора после открытия редактора дождётся окончания предыдущей реакции и минимального интервала. Перетаскивание, клики, открытые окна HUDI, меню, избранное, запрос модели и пауза блокируют реакции. Действия пользователя имеют приоритет; отключение настройки и смена питомца снимают системные обработчики и очищают очередь.

Проверка: `HUDI.exe --verify-desktop-reactions <папка>`. Отчёт `desktop-reactions-tests.json` включает очередь, тайминги, настройку, приоритеты, доступность собственных анимаций и подключение системных обработчиков без синтетического ввода.
