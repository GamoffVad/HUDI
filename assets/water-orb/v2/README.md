# Водяная сфера v2 — спокойное внутреннее движение

Исправлена версия с заметным изменением силуэта. Основа — одно почти круглое
изображение, сгенерированное встроенным `image_gen` по кадрам пользовательского
видео. Разница осей исходной сферы составляет примерно 0,56%.

Контур и основной блик зафиксированы. Внутренняя текстура непрерывно и слабо
смещается по периодической функции; амплитуда не превышает 3 пикселей на кадре
256 × 256. Последовательность не использует переходы между разными рисунками.
Период — 6 секунд, 300 кадров, равномерные интервалы 20 мс (50 кадров/с).

- `water-orb-preview.gif` — просмотр на тёмном фоне.
- `water-orb-loop-green.gif` — цикличный GIF на зелёном фоне #00FF00.
- `water-orb-loop.apng` — цикл с полноценной полупрозрачностью.
- `water-orb-green.png` — неизменённый оригинальный сгенерированный исходник.
- `water-orb-base-alpha.png` — исходная сфера после хромакея.
- `frames-alpha/` — 300 прозрачных PNG-кадров.
- `alpha-check.png` — одна фаза на разных подложках.
- `motion-contact.png` — восемь фаз одного цикла.
- `manifest.json` — проверка формы, неподвижности контура и стыка.
- `prompts.md` — точный промпт и источник референса.

GIF не поддерживает мягкую полупрозрачность; для отрисовки поверх рабочего
стола нужны APNG или PNG-кадры. Тёмный фон превью служит только для просмотра.

Подготовка ресурсов воспроизводится из корня проекта командой
`python tools/prepare-water-orb-v2.py` (Pillow, NumPy, OpenCV). Зелёный фон
исходника удалён хромакеем с сохранением мягкой альфы. Внешние платные сервисы
не использовались. Версия v1 сохранена отдельно. Эти материалы пока не
подключены к установленной версии HUDI.
