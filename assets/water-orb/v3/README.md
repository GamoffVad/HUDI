# Водяная сфера v3 — более заметное перетекание

Сохранён почти круглый исходник v2. Усилено только внутреннее движение:
амплитуда поля смещения увеличена с 3 до 14 пикселей на кадре 256 × 256,
длительность цикла сокращена с 6 до 5 секунд. Внешний контур остаётся
неподвижным. Равномерный шаг — 20 мс, 250 кадров на цикл.

- `water-orb-preview.gif` — просмотр на тёмном фоне.
- `water-orb-loop-green.gif` — зацикленный GIF на зелёном фоне.
- `water-orb-loop.apng` — анимация с полупрозрачностью.
- `frames-alpha/` — прозрачные PNG-кадры.
- `water-orb-green.png` — сохранённый исходник v2 без изменений.
- `motion-contact.png` — восемь фаз движения.
- `alpha-check.png` — прозрачность на разных подложках.
- `manifest.json` — проверка контура, плавности и стыка.
- `motion-comparison.json` — сравнение заметности движения v2 и v3 в размере 80 пикселей.

Новой генерации изображений не было: изменены параметры существующей
анимации. Промпт исходного изображения, созданного встроенным `image_gen`,
сохранён в `prompts.md`. Внешние платные сервисы не использовались.

GIF не поддерживает мягкую полупрозрачность. Для отрисовки над рабочим
столом нужны APNG или PNG-кадры. Тёмная подложка превью нужна для просмотра.

Повторная подготовка из корня проекта:
`python tools/prepare-water-orb-v3.py`. Скрипт использует общий код
`tools/prepare-water-orb-v2.py`; нужны Pillow, NumPy и OpenCV.

Это обновлённые ресурсы анимации; установленная версия HUDI не изменена.
