# Водяная сфера для HUDI

16 исходных фаз сгенерированы встроенным инструментом `image_gen`. Из них
подготовлен цикл из 128 кадров размером 256 × 256 пикселей, длительность —
4 секунды. Контур становится слегка овальным, водяные блики перемещаются.

## Файлы

- `water-orb-green-sheet.png` — оригинальный сгенерированный лист 4 × 4 на зелёном фоне.
- `water-orb-loop-green.gif` — бесконечный GIF на ровном зелёном фоне #00FF00.
- `water-orb-preview.gif` — просмотр цикла на тёмном фоне.
- `water-orb-loop.apng` — анимация с полноценной полупрозрачностью.
- `water-orb-alpha-sheet.png` — 16 вырезанных ключевых кадров, лист 1024 × 1024.
- `frames-alpha/` — все 128 кадров PNG с альфа-каналом.
- `frames-green/` — те же кадры на зелёном фоне.
- `alpha-check.png` — проверка прозрачности на трёх разных подложках.
- `manifest.json` — параметры и результаты проверки стыка и альфа-канала.
- `prompts.md` — промпты генерации и журнал попыток удаления фона.

GIF поддерживает только полностью прозрачные или непрозрачные пиксели.
Для мягкой прозрачности водяной оболочки в приложении используйте APNG или
последовательность `frames-alpha`; зелёный GIF сохранён для работы с хромакеем.
Тёмная подложка `water-orb-preview.gif` служит только для просмотра.

## Подготовка

Генерация исходника: встроенный `image_gen`, без внешнего API.
Две попытки удаления фона генератором оставили артефакты, поэтому итоговый
альфа-канал извлечён хромакеем из исходного зелёного листа. Форма и блики
взяты из этого исходника. При интерполяции учтена прозрачность; последний
ключевой кадр также интерполируется в первый, без обратного проигрывания.

Воспроизведение подготовки из корня проекта:

```text
python tools/prepare-water-orb.py
```

Нужны Python, Pillow, NumPy и OpenCV. Это готовые ресурсы; подключение к
отрисовке сфер в установленной версии HUDI выполняется отдельно.
