# Шесть выразительных анимаций Инка

Созданы по запросу пользователя с обновлённым промптом desktop-pet-builder: неподвижная камера, ровный зелёный фон, нейтральный свет без зелёной засветки, полный силуэт и возврат в исходную позу. Kling 3.0 Standard, 8 секунд, 960 × 960, 24 кадра/с, без звука.

Выбранные версии и статусы указаны в `selected.json`:

1. `look-around.mp4` — осмотр по сторонам.
2. `surprise-v2.mp4` — удивление, исправленная версия без рта и зрачков.
3. `temple-v2.mp4` — жест у виска, **черновик с дефектом**: модель снова нарисовала светлые кружки рядом с пальцем. Не считать готовым к установке.
4. `skeptical.mp4` — недоверие, скрещённые руки.
5. `shrug.mp4` — пожимание плечами.
6. `dance.mp4` — короткий танец.

Две дополнительные адресные попытки: удивление исправлено; нарисованные кружки у виска остались. Повторные платные запуски остановлены. Начальный баланс 128, израсходовано 96 (72 за шесть сцен и 24 за два исправления), остаток 32.

Все 193 кадра каждой выбранной версии проверены на границы; обрезания силуэта не обнаружено. Для каждой сцены осмотрены 16 поз с пробным маттингом на цветной подложке. Отчёты `*/qa.json` и контактные листы `*/contact-sheet.jpg`. Позы начала и конца близки, но не попиксельно идентичны. Полная производственная раскадровка и установка не выполнялись.

Первые версии `surprise.mp4` и `temple.mp4` отклонены, сохранены только для происхождения и сравнения. Инк не возвращён в коллекцию.
