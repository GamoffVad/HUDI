# Инк: пробный цикл с выбором движения моделью

Пользователь заказал один циклический ролик на усмотрение Higgsfield с нашими вариантами и обновлённым промптом desktop-pet-builder. Генерация Kling 3.0 Standard, 8 секунд, без звука, квадратный кадр, одинаковый начальный и конечный референс.

Модель выбрала настороженные взгляды и поправление капюшона. Оригинал: `ink-loop.mp4`. Запрос и происхождение: `request.json`, `submission.json`, `result.json`. Задание: `b2d8e8f1-d06c-4f39-86f6-6a5774396e0a`. Списано 12 кредитов; баланс 140 → 128.

Перед запуском исходное изображение проверено с пробным удалением фона на белом, тёмном и пурпурном фоне (`reference-preflight.jpg`). В исходном видео декодированы все 193 кадра. Проверки границ и маттинга записаны в `qa.json`, выборочные позы — в `contact-sheet.jpg`. Совпадение начальной и конечной стойки не означает попиксельного совпадения; видео остаётся образцом для просмотра, а не готовым установленным пакетом.

Инк не добавлен обратно в коллекцию. Старые удалённые видео не восстановлены.
